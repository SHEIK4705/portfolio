YAAR — Empowering Entrepreneurs & SHGs

A responsive static website to showcase YAAR’s programs: entrepreneur training, SHG marketplace, MSME courses and robotics kits — designed to boost visibility and participation.

Preview: yaar.co.in Contact

Project Abstract

YAAR is a static website built to amplify the impact of a community organisation that supports entrepreneurs, students, self-help groups (SHGs), MSMEs, and tribal artisans. The website is intentionally lightweight and fast, using HTML, CSS, JavaScript and Tailwind CSS for a responsive, accessible UI. Key goals were to present programs clearly, promote SHG products, provide training details, and showcase robotics kits — all while keeping maintenance simple for the client. The site is designed to be easy to host on static hosts (Netlify/Vercel/GitHub Pages), and to be editable by non-technical staff via clear file structure and content blocks.

Project Objectives

  • Deliver a modern, mobile-first static website for YAAR using HTML, CSS, JS and Tailwind CSS.
  • Make programs and services (Entrepreneur Development, MSME Training, Robotics Kits, SHG Marketplace) easy to find and understand.
  • Showcase impact metrics and testimonials to build trust with stakeholders and funders.
  • Provide simple seller profiles and product pages to support SHG product promotion.
  • Include clear CTAs for applications, partnerships, and contact so visitors convert into participants.
  • Ensure the site is fast, SEO-friendly, and easy to update without a complex backend.
  • Prepare a foundation for future upgrades (CMS, payments, multilingual support).

Key Features

Home Page

Mission statement, rotating banner for promotions (e.g., new robotics kits), quick links to programs, animated impact counters, testimonials, and prominent CTAs.

Entrepreneur Development

Program pages for Business Model Canvas, Financial Literacy, and Marketing — resource hub with PDFs and videos, application form for incubation/mentorship.

SHG Product Marketplace

Category-based product listings (Handicrafts, Pickles, Herbal Products, Apparel), seller profiles, product badges for authenticity, and a simple inquiry/checkout flow suitable for a static site.

MSME Training & Robotics Kits

Certified course listings, calendar and registration links; robotics kit catalog and video tutorials with a "Build Your Kit" wizard idea (static wizard simulated).

Technologies Used

HTML5 CSS3 JavaScript Tailwind CSS Swiper.js Vanilla.js AOS (Scroll Animations) Figma (design)

Planned Enhancements

  • Simple CMS integration to allow non-technical staff to update pages (e.g., Netlify CMS or Forestry).
  • Payment gateway & order management for SHG marketplace (upgrade to dynamic backend).
  • Multilingual support (Tamil + English) for wider local reach.
  • Admin dashboard for product & course management (future MERN or Next.js upgrade).
  • Lightweight analytics tracking and SEO improvements for local discovery.
