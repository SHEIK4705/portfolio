# Portfolio Website

This repository contains the code for a personal portfolio website. It showcases various projects and skills in web development.

## Projects

Here are some of the projects featured in this portfolio:

### Grammar Base

An e-learning platform designed to help first-year engineering students learn English grammar. It features interactive quizzes, AI-powered tools, and a voice assistant.

- **Technologies:** HTML, CSS, JavaScript, Bootstrap, PHP, MySQL, OpenRouter API, PHPMailer

### Airosys

A responsive website for an AC and home appliance service company. It includes a gallery and an admin panel for content management.

- **Technologies:** HTML, CSS, JavaScript, Tailwind, PHP, MySQL

### NoteMate

An academic collaboration platform for students and faculty. It allows for homework submissions, online tests, and a help request system.

- **Technologies:** HTML, Tailwind CSS, JavaScript, PHP, MySQL, OpenRouter API

## Tech Stack

This portfolio and the projects within it utilize a variety of technologies, including:

- **Frontend:** HTML, CSS, JavaScript, Tailwind CSS, Bootstrap, React
- **Backend:** Node.js, Express.js, PHP
- **Databases:** MongoDB, MySQL
- **Mobile:** Flutter
- **Other:** Python, Canva, Git, GitHub, VS Code

## How to View

To view the portfolio website, simply open the `index.html` file in a web browser.
